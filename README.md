# 🚀 Task 6: Host a Static Website with GitHub Pages

## 📌 Project Overview

This project demonstrates how to create and deploy a static website using **HTML, CSS, Git, and GitHub Pages**. The website is hosted for free and is accessible through a public URL.

## 🎯 Objective

To learn how to deploy a static website using GitHub Pages and customize its appearance with CSS.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## ✨ Features

- Responsive website design
- Personal introduction section
- DevOps technical skills section
- Featured project section
- GitHub and LinkedIn profile links
- Free website hosting with HTTPS

## 📂 Project Structure

```text
github-pages-task6/
├── index.html
└── README.md
```

## ⚙️ Deployment Steps

1. Created an `index.html` file with HTML and CSS.
2. Initialized a Git repository.
3. Created a new GitHub repository.
4. Pushed the project files to the `main` branch.
5. Opened **Settings → Pages**.
6. Selected `main` as the publishing branch and `/ (root)` as the folder.
7. Enabled GitHub Pages and verified the deployment.
